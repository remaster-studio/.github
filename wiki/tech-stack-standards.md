# Technical Stack Standards

Remaster Studio strictly deploys resilient, production-ready, type-safe application layers to eliminate tech debt permanently.

### Frontend Engine Specification
- **Core Framework:** Next.js (App Router execution contexts) / React 19.
- **State Topologies:** Zustand for localized client state; TanStack Query for caching asynchronous server states.
- **Styling Protocols:** Tailwind CSS v4 maximizing native utility performance patterns.

### Backend Infrastructure Specifications
- **Execution Environments:** Node.js LTS executing strict TypeScript configurations.
- **API Architectural Patterns:** Type-Safe REST interfaces via tRPC or clean GraphQL graph systems.
- **Persistence Layers:** PostgreSQL utilizing Prisma ORM or Drizzle for strict migration safeties.
